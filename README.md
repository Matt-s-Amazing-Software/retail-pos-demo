# Retail POS demo

A small point-of-sale web app with **synthetic data** (a made-up gift shop). It exists as a realistic, living sample
project: real pull requests with Jira ticket keys in their titles, real GitHub releases, and a UI that is deployed
to a public URL so tests, screenshots and tutorials can be generated against it.

- No backend, no accounts, no real data. Everything is kept in your browser's local storage.
- Open the deployed site, or serve this folder with any static server (`python3 -m http.server`).
- Run the unit tests with `npm test` (Node 20 or newer).

Each pull request title starts with the Jira key of the ticket it implements (for example `KAN-13: ...`).
